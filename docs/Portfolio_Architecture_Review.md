# Portfolio Architecture Review

The four projects intentionally cover different layers of AWS security:

1. **Network plane** — route control, inspection, segmentation, flow visibility.
2. **Identity plane** — bounded permissions, emergency access, organization-level guardrails.
3. **Detection plane** — security telemetry, finding aggregation, investigation and alerting.
4. **Application plane** — authenticated API access, WAF, encryption, private service connectivity.

Together they demonstrate prevention, detection, response, and recovery rather than a single-control security portfolio.
