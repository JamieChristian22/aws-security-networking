# Detection & Incident Triage Runbook

1. Validate alert source and finding ID.
2. Identify account, region, resource, principal, and timestamp.
3. Pull related CloudTrail events.
4. Determine whether activity is expected.
5. Contain compromised identity/resource if needed.
6. Preserve logs.
7. Remediate root cause.
8. Close with timeline, impact, evidence, and prevention action.

HIGH/CRITICAL findings require explicit owner and closure evidence.
